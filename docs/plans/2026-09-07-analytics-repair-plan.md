# 实施计划

1. 属性与付款：用真实映射/乱序测试锁定失败，修复内联存储与付款优先级；补充历史恢复及PG14验收材料。
2. 后端Analytics：依次测试并修复SQL、成功/失败时间、身份、人工复发、缓存周期和精确明细范围；保留兼容接口。
3. 前端：测试并修复切片周期校验、上海formatter、固定阶段、桶明细和多币种/陈旧提示。
4. Noindex：复用现有策略增加仅指定项目的覆盖，测试正常/密码/已封禁及NGINX链路。
5. 总体验收：审查所有diff，运行后端测试、前端测试/lint/build，尽力准备隔离PG14；编写上线/恢复手册与未完成项。
6. 经营行动：按P0数据与安全、P1留存与访谈、P2SEO/GEO渠道试验和持续运维列出负责人动作、指标、依赖。
