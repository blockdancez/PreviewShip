# PreviewShip 增长转化优化

目标：让已有搜索流量更顺畅地完成发布、保存项目和购买适用套餐。沿用 2.0.1；本轮为本地代码交付，不包含提交、生产部署、真实付款或外部发信。

## 数据基线与决策

2026-10-26 只读复盘：数据库比较北京时间 09-26 至 10-25 与 08-27 至 09-25；Google/Bing 比较完整 28 日 09-26 至 10-23 与 08-29 至 09-25。经营事实排除 INTERNAL；成功和留存使用保留的 SYSTEM 成功事件，避免版本/项目删除影响。

| Google AI 曝光 | 15,333 | 33,855 |

年付 75.60 美元付款由 4 笔降至 1 笔，解释现金差额 226.80 美元；实收不是 MRR。成熟新注册 7 日付费为 19/1,007→10/1,151；每人观察满 7 日，但本期注册窗口只有 23 日，比较率而非人数增减。上述趋势不能证明价格过高或归因于某个界面问题。

当前有效付费 45 人，项目中位数 2；28 人最近 30 日没有新发布事件，可能仍需要保留现有链接。套餐内容优先解释持续保留、密码访问和交付价值。外部 campaign 仅捕获 10 条 landing，尚不足计算渠道 ROI。

## 事件契约

沿用第一方 schemaVersion=2、服务端接收时间、匿名/获客身份桥、CSRF 和 INTERNAL 排除。新增客户端事件版本 `client_flow_version=growth_2026_10_26`，结合实际发版时间切分前后基线；客户端版本不能替代服务端成功/付款事实。事件失败不得阻断发布、认证或支付。禁止恢复第三方分析脚本。

| 事件 | 触发时机 | 必要维度 | 去重/权威 |
| --- | --- | --- | --- |
| pricing_plan_selected | 用户主动选择月/年套餐 | plan、billing_cycle、surface、trigger | 一次点击一次；不等于付款 |
| pricing_plan_presented | 所选套餐进入视口 | plan、billing_cycle、surface、trigger | 同会话和同上下文一次 |
| paywall_viewed | 升级/到期提示或套餐区真实可见 | surface、placement、trigger、subscription_status；适用时 project_id/deployment_id | 会话、账号、位置和项目上下文去重；记录曝光口径版本 |
| pro_feature_intent | 免费用户主动选择锁定能力 | feature=protected_access、surface、trigger | 只记录意图，不记录密码 |
| deploy_validation_failed | 上传前校验确定失败 | error_code、input_type=file/html/markdown、input_mode、surface、phase=preflight | 三入口复用 typed 错误和属性助手；未知准备错误只展示通用失败，不冒充已知校验；服务端失败不重复计入 |
| guest_claim_started / guest_claim_failed | 自动/手动认领请求开始/失败 | surface、trigger=auto/manual、error_code（失败） | 请求级；不含 claim Token；成功沿用服务端 guest_claim_completed |
| content_primary_cta_click | 内容主 CTA | surface、page_id、locale、input_mode、publish_intent | 数据库沿既有规则归一为 cta_clicked，source_event_name 保留来源 |

旧客户端 paywall 缺 surface 时仅从既有 placement 补充新入库事件；不迁移或重写历史数据。历史挂载曝光和新可视曝光必须分开评估。

## 实施顺序

1. 先补行为回归和共用的安全跳转、可视曝光、校验错误语义。
2. 付费认证链路、游客恢复、内容承接并行实施，按文件边界协作。
3. 整合控制台锁定特性和安全草稿恢复；检查事件在客户端和服务端的实际规范化结果。
4. 运行前端全量单测、类型、lint、完整构建与 SEO 校验；后端定向测试和完整打包。
5. 本地浏览器验证桌面/移动端的首次发布输入、错误恢复、认领失败与套餐选择；独立评审修复遗漏。
6. 将实际结果更新到本文，并在发布入口记录顺序和生产验收边界。SQL 无新增。

## 发布验收与观察

代码发布必须另行授权。建议先后端兼容补丁，再 Console；保留现有审核、权限、额度和支付 Webhook。

- 生产验收：匿名月/年选择→注册/登录→Billing 保留选择；实际付款需明确授权后另验。Google OAuth 回跳需真实登录验收。
- 生产验收：校验失败可纠正重试，认领额度失败可恢复，过期认领不误称链接已在线。
- 埋点验收：新曝光带口径标识、必要维度齐全；阶段成功以服务端 SYSTEM 事件/付款账本为准。
- 增长观察：按发布前后完整 28 日比较成熟 7 日激活/付费、Checkout session 完成率、跨日再次发布、认领恢复率。修复验收不以收入必然提升为前提。
- 页内上传 v3 保留 50/50；每臂达到既定 500 访客且满足观察期再决策，不根据当前 25.5%/28.8% 小样本全量放开。
- 运营：补外部公开 URL、UTM 与结果；按素材跟踪 landing→发布→注册→付费。404 逐 URL 判断，保留有意 noindex；暂不批量修改索引策略。
- 后续研究：有限期限单项目保留套餐、价格、取消原因、支付失败恢复；本轮不创建新套餐、不调整价格、不自动发信。

## 全面复审补修

以下问题通过实际 handler、重渲染/清理、异步调度或浏览器布局复现后修复，未把仅复跑原有断言当成独立评审。

| 优先级 | 问题及影响 | 最终修复与验收 |
| --- | --- | --- |
| P1 | OAuth 购买目标 Cookie 原为 host-only，无法送到实际 `api.previewship.com`；失败回跳固定登录页也丢失目标 | 生产域使用 `.previewship.com` 和 HTTPS Secure，清理 host-only/域副本；成功与失败共用安全目标校验，失败登录页保留 returnTo。localhost 保持 host-only；非法外链和编码绕过仍拒绝 |
| P1 | Billing 清 URL/重渲染会停止 Webhook 等待；旧月付 ACTIVE 会被误当年付升级完成；后退缓存页保留旧锁 | 返回记录与轮询生命周期分离；等待实际目标套餐 ACTIVE，限制并发和 30 次轮询；超时可重试，pageshow 释放跳转锁，仍防同步双击。Stripe 返回使用已校验周期生成 plan，保留语言与来源；不自动 Checkout |

| P1 | 认领在卸载间隙成功后重挂会重发已消费 Token；失败参数绕过意图时限，迟到响应可能覆盖新草稿 | 成功结果在同一运行期按账号/Token 最多复用 5 分钟、32 项；失败不自动循环，30 分钟时限与手动恢复分开；准备、上传、重试和认领完成前检查账号/草稿/挂载。草稿类型、日期和 URL 校验；明确 404/410 可主动退出旧进度 |

| P2 | 异步出现的曝光目标漏报、后台页误报、跨页面/语言实验复用旧关联；禁用存储时身份漂移 | 回调 ref 跟踪目标；确认身份后观察，服务端公开入口也按已有 Session 排除 INTERNAL，仍不信任公开资源 ID；实验显示与关联绑定页面/语言。禁用存储时匿名/会话/获客 ID 在当前页面稳定，仍可旋转/重置 |

草稿维持 localStorage 单一持久来源；本地写入失败时只使用当前页面内存覆盖，并能感知其他标签页更新。没有引入 sessionStorage 备份与主存储的新旧竞争。

限制：禁用浏览器存储时仅当前页面/SPA 可用内存草稿兜底，完整刷新或 OAuth 跨页无法保证恢复；无 IntersectionObserver 的浏览器不伪报曝光，仍可正常操作。真实 OAuth、Stripe 付款、生产埋点和增长指标均须发版后另验。
