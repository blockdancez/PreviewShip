# 审核规则、模型调用与会员权益

本版本普通发布与审核分离；2026-10-12 补丁补齐编码视图、变量外发及风险未决处置。继续复用已有模型输入规划与证据校验。规则分值不是恶意概率，也不是 Google/Cloudflare 的内部判定分数。

## 何时调用 AI

本轮 2026-10-14 共享托管规则优化由用户批准实施，尚未提交/部署。审核把 PreviewShip 视为多租户静态托管平台：`xxx.previewship.net`、兼容域名或自定义域名不是客户品牌身份；客户可使用自己的品牌、自有账户、独立 API 或合法身份服务。域名不同、OAuth/SSO 品牌词、未知后端所有者、缺少注册/重置页面均不能单独证明仿冒或外传，也不要求用户从静态源码证明授权。

判断围绕凭据归属与真实行为：自有账户认证、正常授权跳转和没有实际收集的原型允许；伪装第三方服务并索取其密码、绕过认证把密码发往机器人/收集端、隐蔽外传或伪造失败仍保持风险检查。“demo/authorized” 页面声明不构成白名单；API 路径或知名服务域名也不能豁免危险行为。候选类别仅是召回线索，不是恶意证明。保留引用校验、确认恶意摘要拦截、风险未决暂隔离与有限自动复核。

策略升级为 `2026-10-14-v9`；扫描器补充 Zoho 品牌召回，避免该类真实钓鱼只有密码框/提交候选。新增合成正反回归，模拟 AI 只验证契约；真实模型评测使用显式开启的测试，仅提交合成源码，不使用用户上传制品。无新增 SQL、接口或前端字段，历史终态记录不会自动重审或解除封禁。

普通发布成功后，后台扫描 HTML/脚本/SVG；只有出现敏感候选才调用 OpenRouter。无候选且扫描完整的文件可由本地规则判定 `PASS`。孤立密码框、品牌文字、压缩脚本、base64 或外部 CDN 不能直接判恶意。

已隔离项目整改仍在渠道创建之前执行同一规则和必要的 AI 审核。相同内容已确认 `HOLD` 的制品继续前置拦截，不通过反复模型抽样变成安全。纯供应商技术故障为 `UNKNOWN`，普通在线版本继续可用。已有实际模型风险但证据未决时暂隔离并自动复核；有明确主动隐藏行为且编码内容无法完整展开时也暂隔离，使用本地 `OPAQUE_CONTENT_UNINSPECTED` 原因，不伪造模型结论。已限制版本仍需通过才能恢复。

## 确认风险的条件

| 类别 | 规则权重 |
|---|---:|
| 品牌仿冒 | 35 |
| 敏感信息收集 | 25 |
| 可疑外传 | 25 |
| 误导跳转或下载 | 20 |
| 隐藏行为 | 25 |

模型证据须定位到实际送审文件、行号与引用，外传还需要真实提交行为支持。解码视图只用于审核，候选、摘录与模型证据均使用其虚拟路径与行号；制品摘要仍来自原上传字节。`MALICIOUS/HIGH`、至少三个类别和三处独立证据、包含外传/误导/隐藏行为且累计至少 75 分，才确认 `HOLD`。另保留已有可独立定位的敏感收集与机器人外传组合门槛；明确敏感读取、实际外传、隐藏/欺骗的独立行为链可确认风险，不依赖凑满类别；明确恶意威胁引用按现有规则阻断。`SUSPICIOUS` 且证据有效时给出中风险建议，分值封顶 74。

规则不执行上传 JavaScript，不做动态浏览器渲染、图片 OCR 或任意外链抓取；静态检测存在覆盖范围，不能宣称全部攻击都可识别。先发布后审有公开窗口；供应商技术异常期间没有保证最长窗口，未完成审核不会被静默标记为通过。

## 有界预算与权益

| 会员权益 | 免费版 | 月付专业版 | 年付专业版 |
|---|---:|---:|---:|
| ZIP 大小 | 15 MiB | 50 MiB | 80 MiB |
| 每月上传量 | 200 MiB | 2048 MiB | 4096 MiB |

这些值未修改。原始 ZIP 解压仍限制单文件 100 MiB、制品合计 128 MiB；规范化后审核文本单文件和累计上限 128 MiB，与既有制品保护边界一致。压缩体积、解压字节和模型输入是不同预算。

Scanner 复用原字节、稀疏页解码和行号，较大 HTML 使用最多 4 MiB 投影，节点上限 20,000。模型每批实际序列化输入默认 48,000 UTF-16 字符、40 个候选，整轮 30 秒、2,500 输出 token；整体放不下时仅证明独立的 HTML 可分组，最多三批、整轮最多四次供应商调用。任何关联组遗漏或放不下都为 `UNKNOWN`，不截取前缀后认定安全。

有限纠正/重试保留先前风险关切与分组结果。同一模型调用轮次的证据/格式修复后 SAFE、低置信度 SAFE、旧 run/hash 不能清除风险；新后台轮次第一次返回的完整、结构化有效 HIGH/SAFE 可以纠正未确认误报。已确认 HOLD 相同摘要不允许重抽。后台最终未完成单独记告警；原制品不会仅因模型格式错误要求普通用户重新上传。

`web-risk-enabled=false` 表示关闭可选 Google Web Risk 引用检查；本地规则和 OpenRouter 仍正常执行。仅在配置好对应官方服务时才启用，`NO_MATCH` 不会降低本地证据风险。

实现依据：[ContentRiskProperties](../../../backend/src/main/java/com/previewship/config/ContentRiskProperties.java)、[ContentRiskScanner](../../../backend/src/main/java/com/previewship/service/ContentRiskScanner.java)、[OpenRouterContentRiskClient](../../../backend/src/main/java/com/previewship/service/OpenRouterContentRiskClient.java)。

## 解码与依赖范围

最多展开三层、32 个视图；主动解码字符累计上限取 `min(maxAnalysisBytes, maxAiChars × 3)`，普通制品总字节权益不变。支持百分号 `%XX/%uXXXX`、严格 UTF-8 的 decodeURIComponent、atob、srcdoc、data HTML/脚本和 HTML Blob。只做静态解析，不执行用户脚本。

唯一字面初始化且未再次赋值的 const/let/var 可关联 fetch/sendBeacon 发送；敏感页面会按需扫描同制品内引用的脚本，包括无扩展名脚本。普通图片编码、普通 API 调用与普通文本解码不能单独判恶意。用户界面标注解码视图，整改可回到对应原文件。

暂隔离的当前版本可独立自动复核：自托管恢复私有部署目录至 current，远程渠道使用完整哈希验证快照重建，包含 CSS/图片/字体/PDF，供应商 READY 后恢复。远程新副本清理坐标保存在私有 NAS journal，落库或删除失败持续对账。历史副本不自动替换 current，明确标为已撤销。

## 账号历史与可信投诉

V42 将确认和疑似安全事件独立保存，项目删除不删除事件；confirmed 摘要精确拦截，疑似不进入恶意摘要名单。风险账号后续提交前置审核；普通账号仍快速异步发布。

管理员可登记在 Cloudflare 核实的 reportId 与站点 URL。入口仅接受 PreviewShip net/cc 单级 HTTPS 子域名，拒绝 userinfo/端口等歧义，不访问举报页面。报告幂等，项目删除或同 slug 重建不把旧投诉自动应用到新项目。本版本不自动接入云厂商邮箱或读取告警；仍需先核实报告再登记处置。Cloudflare 边缘限制与平台处置仍须分别验收。

## 证据可靠性

附加外传错引同样不应拖垮已核实的危险链：引用真实性、重复 ID 和 15 条上限先验证；只有 MALICIOUS/HIGH 且另有一个经原规则核实的真实提交目的地时，才剔除不包含目的地的附加引用，再交服务层核实敏感输入及完整危险链。仅一个 URL 仍不能确认风险，缺失/重复引用也不能被过滤成有效结果；SUSPICIOUS、低置信或无独立目的地仍保留未决。机器人候选也可利用原一次纠正预算。真实模型评测沿实际三轮自动复核上限保留风险记忆，不把偶发错引当成功，也不增加生产调用预算。

合成真实模型评测补齐两项证据可靠性：没有具体品牌身份的邮箱/文档措辞不应捏造品牌类别；若额外品牌证据不受支持，只有原有严格 `MALICIOUS/HIGH + 独立敏感输入 + 独立机器人目的地` 组合仍可确认 HOLD，附加类别不参与评分或用户证据。其他不足或低置信情况继续 UNKNOWN。变量型 fetch 引用不包含目的地时，客户端复用服务层相同的提交目标匹配并在已有一次纠正预算内要求改选 URL 字面声明；保留原风险关切，纠正时改口 SAFE 不能放行。没有增加模型调用/输入预算。
